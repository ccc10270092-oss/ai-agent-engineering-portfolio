## 三、⚠️ LLM 接入点（此处留空，由你决策）

**当前 LLM 模块处于「留空」状态**：未接任何真实模型，运行时自动使用离线
Mock（模板化话术），保证无 Key 也能端到端跑通。

要接入真实模型，**只做一处决策、只改一个文件，无需改任何代码**：

1. 复制模板：`cp .env.example .env`
2. 在 `.env` 里填三项：
   ```
   LLM_MODEL=你的模型名
   LLM_API_KEY=你的密钥
   LLM_BASE_URL=你的 OpenAI 兼容接口地址
   ```

决策点仅为「选哪个模型 / 哪个服务商」。填好后，`demo.py`、前端「智能问答」
和「内容生成」三处会自动切到真实生成，其余逻辑不变。

> 需要切换向量后端（simple → chroma）时，另在 `.env` 加
> `RETRIEVAL_VECTOR_BACKEND=chroma` 并 `pip install chromadb`——这与 LLM 无关，属可选。
>
> **知识库已本地持久化**（`data/docs.db` + `data/fts.db` + `data/chroma/`），重启不丢；
> 支持前端上传 txt / md / csv / pdf / docx 入库、单篇删除与一键清空。
> embedding 默认本地模型 bge-small-zh-v1.5（512 维，首次运行自动下载约 100MB 到
> `data/models/`，国内建议 `.env` 设 `HF_ENDPOINT=https://hf-mirror.com` +
> `HF_HUB_DISABLE_XET=1`）；未装 fastembed 或加载失败自动回退特征哈希。
> 切换 embedding 模型后维度变化会自动重置向量库（启动日志有告警），需重新入库。
>
> **商品目录已持久化**（`data/products.db`，内置 P001~P003 种子）：产品文档入库时
> 按启发式自动登记商品（内容生成页立即可选），前端「管理商品」弹窗支持增删改查；
> 手动编辑过的商品不再被文档覆盖，删除文档不影响已登记商品。
