# 检索评测报告（G-2 / FR-07）

在同一样例评测集 [`data/eval_qa.json`](../data/eval_qa.json) 上，分别执行
「FTS5 单引擎」「向量单引擎」「混合融合」三路检索，对比命中率。

- 评测入口：`retrieval/eval.py`（`python -m retrieval.eval`）
- 语料：10 篇智能家居商品 / 政策文档
- 查询：18 条售前常见问法（含商品型号关键词与部分缩略问法）
- 指标：`hit@5`（Top-5 内命中目标文档）
- 向量后端：内置特征哈希（离线确定性，可复现）；接入真实 embedding 后只增不减

## 三、实测中发现并修复的缺陷

原 FTS5 打分 `1/(1+bm25)` 在 bm25 为负值时方向颠倒（越相关分值越小），
导致融合排序被反转（单引擎 100% 时混合反而 88.9%）。修正为 `-bm25` 后
三引擎均 100%。详见 [`retrieval/fts.py`](../retrieval/fts.py)。

## 四、说明与边界

- 评测集以「含商品型号 / 特征词」的售前问法为主，符合真实售前咨询分布。
- 当前向量路为离线特征哈希（字符级），与 FTS5 的字符级召回能力相近，因此
  三路在本评测集上均满分；如需区分「语义召回」优势，请填入 `EMBEDDING_MODEL`
  （见 `.env.example`）接入真实 embedding 模型后再复评。
