## 三、技术管理备注

1. **自研 vs 三方边界清晰**:自研部分集中在三处——LLM 客户端(标准库 urllib)、safe_call 可靠性框架(重试/退避/降级)、PII 脱敏与特征哈希兜底;其余全部采用成熟开源组件,降低维护成本。
2. **全链路多级降级设计**是本技术栈的主线:LLM 无 Key→Mock、chromadb 缺失→特征哈希、fastembed 加载失败→哈希回退、工具失败→重试≤2→降级回答——任何单点缺失系统都可运行,这是「演示可用」与「持续可用」的区别。
3. **版本策略**:核心依赖(LangChain/LangGraph/pandas/PyYAML)精确锁定;网关与前端组件约束最低版本(`>=` / `^`),兼顾安全补丁与兼容性。
