## 二、异常场景覆盖（AC-07.2）

| 场景 | 验证方式 | 结果 |
| --- | --- | --- |
| 工具调用失败 | `FailingTools` 抛异常 → 重试 2 次 → 降级回答 | ✅ 无异常抛出 |
| 超步数护栏 | 注入 `AlwaysRouter`，`max_steps=3` 强制终止 | ✅ 不无限循环 |
| 内容生成节点失败 | patch 生成器抛异常 → 重试 → 跳过节点(FAILED) | ✅ 不整体报错 |
| 空知识库 | 检索返回空列表，回答走兜底话术 | ✅ 不崩溃 |
| 100 次随机问答 | 循环调用 `System.ask` | ✅ 崩溃 0 次 |
